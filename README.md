# 🪓Hangman Game

## Description

Hangman is a classic word guessing game built with HTML, CSS, and JavaScript. The player tries to guess the hidden word by suggesting letters one at a time. Each incorrect guess brings the player closer to losing the game.

This project is a simple and interactive implementation suitable for learning JavaScript DOM manipulation, CSS styling, and basic game logic.

<hr/>

## 🎮 Features

- Random word selection from a predefined list

- Display of underscores for unguessed letters

- Track of correct and incorrect guesses

- Visual representation of Hangman progress

- Reset/restart game functionality

- Responsive design for different screen sizes

  <hr/>

## 💻 Technologies Used

HTML5 – Structure of the game

CSS3 – Styling, animations, and layout

JavaScript (ES6) – Game logic, DOM manipulation
 
  <hr/>

## 🛠️ How to Play

The game will display a hidden word as underscores (_).

Click on letters or type them on your keyboard to guess.

Each incorrect guess draws part of the Hangman.

Guess the word before the Hangman is fully drawn to win.

Click Restart to play again
